## 📱 Visão Geral

O **Desafio dos 100** não é apenas um rastreador de despesas. É um Progressive Web App (PWA) de arquitetura moderna que une gamificação com uma Interface de Usuário (UI) inspirada nas maiores fintechs do mundo (Stripe, Apple Card, Revolut). 

O sistema permite que dois usuários se conectem em um mesmo "grupo" (casal) para preencherem, juntos, um mapa de 100 depósitos progressivos, acompanhando o avanço em tempo real.

### ✨ Principais Features

* **🤝 Sincronização de Casais:** Sistema de convites via código/link onde dois perfis se unem em uma mesma jornada financeira.
* **🎮 Gamificação Visual:** Grade interativa de 100 passos que se ilumina com a progressão e Cápsula de Progresso central com animações em CSS puro.
* **💅 Design Premium & Minimalista:** UI projetada no estilo "Minimalismo Financeiro", utilizando a paleta `Zinc` do Tailwind, cores sólidas, tipografia refinada e modais imersivos.
* **💸 Geração Inteligente de Pagamento:** Fluxo de depósito blindado contra erros com modais de confirmação de alto padrão.
* **☁️ Cloud Storage Integrado:** Upload e renderização de fotos de perfil (Supabase Storage).
* **📱 Progressive Web App (PWA):** Instalável direto no smartphone com experiência fluida de app nativo.

## 🛠️ Stack Tecnológica

O projeto foi construído utilizando as ferramentas mais modernas do ecossistema web:

* **Framework:** [Next.js 15 (App Router)](https://nextjs.org/)
* **Linguagem:** [TypeScript](https://www.typescriptlang.org/)
* **BaaS (Backend):** [Supabase](https://supabase.com/) (PostgreSQL, Auth, Storage)
* **Estilização:** [Tailwind CSS v4](https://tailwindcss.com/)
* **Componentes Base:** [shadcn/ui](https://ui.shadcn.com/) (Customizados)
* **Ícones:** [Lucide React](https://lucide.dev/)

## 🎨 Filosofia de Design (UI/UX)

O aplicativo foge do clichê de "gerado por IA". Ele adota uma postura **sólida, segura e luxuosa**, características essenciais para aplicações financeiras. 
* **Core:** Fundos pretos sólidos e escala chumbo (`bg-zinc-950`).
* **Sotaque:** Verde Dinheiro para indicar ações positivas e sucesso.
* **UX:** Modais focados que bloqueiam o scroll e direcionam a atenção no momento do depósito para evitar toques acidentais e proporcionar uma experiência 100% confiável.
